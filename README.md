# Luma website

This branch contains the static download page for Luma. Open `index.html` in a browser or serve the repository root with any static web server. No build step or dependencies are required.

The main download button links to the `Luma.dmg` asset in the [Prod release](https://github.com/JoshOn360Hz/LumaApp/releases/tag/Prod). Update the link in `index.html` if the release asset location changes.
